# KHS Music Studio — 다운로드

개인용으로 개발한 Windows 음악 제작 프로그램입니다. 영화음악 전용이 아닌 일반 작곡·녹음·편집용 DAW입니다.

## Windows 설치 파일
- Windows 64비트 설치 프로그램: 릴리스 페이지의 KHS.Music.Studio_0.9.17_x64-setup.exe
- 브라우저 작곡실(설치 없이 이용): https://khs-music-studio-web.pages.dev/
- 원본 소스: 릴리스의 KHS-Music-Studio-v0.9.17-khs.1-source.zip

## 주의 사항
- 이 릴리스는 테스트 중인 Windows 베타입니다. 출처 검증에 도움이 되도록 SHA256SUMS.txt를 첨부했습니다.
- 설치 파일은 아직 코드 서명되지 않았습니다. 앱을 설치하기 전에 Windows 보안 경고와 파일 출처를 확인하세요.
- FL Studio, Image-Line의 공식 제품 또는 파생 제품이 아닙니다.
- WAVE 오픈소스 기반으로 제작되며 AGPL-3.0-only 라이선스를 따릅니다. 전체 대응 소스와 저작권 고지를 릴리스에 함께 제공합니다.
- 웹 프로젝트 JSON과 Windows 프로젝트 .wave는 직접 호환되지 않습니다. MIDI/WAV로 자료를 교환하세요.
- 설치 및 장치별 실제 음성 입출력 테스트는 추가 검증이 필요합니다.
